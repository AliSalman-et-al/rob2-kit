The preferred scientific order is D3, AE Result selection/D5, D4, then D1/D2.
This is priority, not a chain of blocking edges. Diagnostic work informs each
scientific slice but need not finish cohort-wide before a supported mechanism can
be fixed. Missing historical artifacts permit an explicit fictional reproduction;
they never permit an invented explanation of a benchmark disagreement.

Slices 13 and 15-17 consume the decision-context contract from 12. Slice 18
consumes the receipt/whole-Trial decision boundary from 05. Slice 19 is the final
integrated candidate wave and therefore waits for all selected slices. A slice
whose intervention proves unjustified completes with its reproducible evidence
and disposition, not an unnecessary code change.

There is no standalone prefactor or wide-refactor migration. Make local simplifying
changes within the behavior they enable. Independent tickets may touch shared
modules; the implementation coordinator assigns one writer at a time or explicit
nonoverlapping ownership. Shared-file scheduling is not a product dependency.

## Proposed verification boundaries

- Primary: existing public MCP/application workflows, exercised as callers.
- Installed host: actual question/text/image delivery and normal recovery.
- Existing independent verifier: persisted Evidence and final artifact integrity.
- Existing evaluator/oracle: official activation and deterministic judgments.
- Existing runner/analyzer: complete evaluation attempts and metric denominators.

Scientific contrasts exercise Source discovery and question answering through the
host. Supplying expected answers directly to the evaluator only tests rule mapping.
No new test-only framework or compulsory second assessor is proposed.
