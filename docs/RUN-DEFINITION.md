# Run-definition reference

Use this reference only while the Run is unconfirmed or when the operator asks
to change its scope. Before a proposal exists, the Project initialization
snapshot and its Source-role work item are authoritative only for inventory and
role review. After Source-role resolution and completed Proposal discovery
review, the latest engine-issued proposal becomes the authoritative candidate
Run definition.

Start by preparing the explicitly selected project root. Inspect and classify
only Sources issued in the current work context, resolve every Source-role
candidate, and complete bounded discovery for each eligible result-bearing
full-text report. Treat Reported endpoint, Randomization, and Arm candidates as
reviewed source observations rather than Run identity. Only attributable human
promotion may declare Outcome targets or establish Randomization and Arm
identity; the later mapping review proposes Trial-specific Results. Discovery
submissions bind to the immutable Project initialization snapshot and work token;
the engine issues the first Run proposal only after every required discovery item
is complete.

Present the compact proposal in plain language. A requested Trial × Outcome
target must be selected, excluded with a readable reason, or explicitly
removed by the operator. Material identity, outcome, analysis, or time-policy
ambiguity remains a decision; do not fill it from file names, abbreviations,
citations, lexical similarity, or general knowledge. Keep Proposal limitations
distinct from competing interpretations, and do not confirm while required
discovery or mapping work is unfinished.

When the operator changes scope, submit complete structured promotions and
selections against the latest proposal token; free-text correction grammar is
not supported. Show the returned semantic difference, complete any resulting
mapping work, and confirm only the latest proposal token with the attributable
human actor returned by the workflow. Confirmation authorizes preparation; it
does not approve findings or reports. Once confirmed, return control to
`rob2-assess`.
