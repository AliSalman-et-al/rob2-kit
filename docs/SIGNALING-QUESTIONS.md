# Signaling-question reference

Use this reference only after the engine has issued a Domain answer work item.
Read the bounded Domain context and submit the permitted typed answers with a
concise evidence-grounded rationale. Cite the returned evidence references and
report unresolved material limitations rather than filling gaps from memory or
general clinical knowledge.

Question wording, applicability, branching, answer interpretation, and
judgment rules are obtained only from the pinned guidance and Logic packs
through the tools. This reference intentionally does not restate official
guidance or Logic-pack rules.

Submit one answer for every active question returned by `get_work_context`, and
omit questions listed as inactive. Use the schema values `yes`,
`probably_yes`, `probably_no`, `no`, or `no_information`. When an answer changes
branch applicability, use the active-question set returned for this work item;
completion means the submitted set equals that active set. A `no_information`
answer also requires the question's complete Search coverage basis.

Keep each answer scoped to the exact issued Result, source, and signaling
question. Use exact frozen passages for factual claims and label any permitted
inference in the rationale. Text about a cited or related trial is out of scope
for the assessed Trial. Do not infer an answer to one active question solely
from evidence addressing another; apply each question's issued wording and
guidance to its own evidence. The engine alone applies branching and derives
Domain and overall judgments from the pinned packs.
