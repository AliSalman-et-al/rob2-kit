Use this reference only after the engine has issued a Domain answer work item.
Read the bounded Domain context and submit the permitted typed answers with a
concise evidence-grounded rationale. Cite the returned evidence references and
report unresolved material limitations rather than filling gaps from memory or
general clinical knowledge.

judgment rules are obtained only from the pinned guidance and Logic packs
through the tools. This reference intentionally does not restate official
