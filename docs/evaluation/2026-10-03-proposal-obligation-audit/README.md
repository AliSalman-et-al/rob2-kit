## Implemented simplification

Before: group_values requires group_id, statistic, value and unit, although statistic may be null. After: group_id, value and unit remain required; statistic is optional and defaults to unresolved null. A source-supported label remains explicit. This removes the requirement to manufacture an internal null field when no label is supplied. No numeric coercion, label/unit inference, aliases, wrapper, new model call or source-entailment code. Canonical records still emit statistic:null; scientific null semantics and historical export versions remain unchanged.

Unchanged-request native replay: attempt 1 construction defects 9 → 7 (two missing null-capable statistic fields); attempt 2 remains 25 because its group values omit value while putting prose in statistic. Both remain rejected. This is reduced construction work, not demonstrated behavioral success. The live schema and bundled reference explain omission consistently.

The public export-skill command was exercised in the current execution environment; exported workflow/reference hashes match the bundled source. No separate rob2 home skill installation was found or changed. This checks installation material, not proof the paid host loaded it.

Focused tests: 18 distinct controls pass across typed proposal routes and the group-statistic full assessment/export lifecycle (initial run 16 passed plus one corrected expectation, then both recovery-feedback controls and documented public examples passed). Invented labels fail source binding; omitted labels conflict with specified clarity; truthful unclear labels persist as null through assessment, export and standalone verification. Ruff, source type and whitespace checks passed. No broad tests, paid inference, full benchmark, merge or CI wait.

Decision: retain the D2 context on general merit; make only this demonstrated optional-metadata simplification. Do not claim that it resolves EMPEROR or that larger unvalidated architectural changes improve scientific accuracy.
