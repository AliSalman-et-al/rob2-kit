## Proposed bounded correction policy — not applied

For a separately approved diagnostic, replace the blanket two-rejection cutoff with at most **four total save attempts** (initial attempt plus up to three host-owned corrections), still stopping immediately on acceptance. Keep 800k total input, 100k uncached input, 5k output, 20 tools, 480 wall seconds and 120 idle seconds unchanged. These independent caps can stop a run before the save-attempt allowance is used.

Permit the next correction only when returned validation demonstrates construction progress: a prior syntactic defect is gone and the request reaches a later validation stage; or valid answers are retained while the active-path missing set shrinks or newly activates a downstream question. Compare normalized error fingerprints by stage, code, field path and active/missing IDs; do not count a changed error string or a changed risk answer by itself as progress. Stop after **two consecutive identical rejected fingerprints**, a return to an already unresolved syntax defect without progress, four total save attempts, or any existing guard. A new evidential/scientific-warrant defect does not automatically earn a mechanical-repair extension.

The monitor could hold these comparison records only for the invocation, alongside its existing counters; no workflow lifecycle change is needed. It must continue to deliver each repair before another model generation, record exactly what feedback reached the model, and report any in-flight overshoot. Model reasoning remains responsible for new active questions; the operator supplies no answers or manual payload repair. Four attempts may still fail to finish an entire branch if the host answers one new question per attempt; it is a small bounded allowance, not a completion guarantee.

This is an explicit policy proposal, not authorization silently exercised. Current launcher, policy JSON and monitor remain unchanged at the two-rejection bound; no limit was increased and no paid run occurred in this pass. Further inference should first settle whether this limited mechanical-correction allowance is desired.
