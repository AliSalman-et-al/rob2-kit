## Linkage before model answers

A reviewer should distinguish these categories using source evidence without model answers:

- **Confirmed/result-explicit:** actual author confirmation or published result identification
  establishes scope. Inference is not author confirmation.
- **Justified primary reconstruction:** reference explicitly identifies trial primary and
  source supports a coherent mapping without a material rival. Record direct support,
  inferences and remaining uncertainty.
- **Genuine mismatch:** outcome, contrast, window, population or analysis materially differs.
  Exclude this current target from comparison with that label.
- **Pending:** a material rival mapping remains unresolved; neither proven mismatch nor
  proof that the human assessment is unusable.

Author confirmation, exact access timestamps and verbatim documentation of every metadata
field are not universal prerequisites. Nonmaterial gaps can remain explicit; outcome,
contrast, window and analysis cannot be silently conflated. Qualified D5 prespecification
inference is a scientific judgment, not a universal label-matching gate.

Use a plain review table: original label/source row, chosen result facets, source passages,
direct/inferred support, competing mappings, decision, reviewer and previous case exposure.
The accompanying JSON preserves original rows/hashes; candidate statuses are discussion
proposals, not certified inclusion decisions. No new schema or framework is needed.

Heemskerk safety versus mortality and Attal responder versus mean pain are genuine
current-target mismatches. Their human evidence may still support resolved alternate results.
Keep these in a separately versioned diagnostic dataset with parent row, original source
hashes and review provenance. Preserve printed labels; new expert adjudication is separate.

## Scoring and limits

Report unchanged published D1–D5 three-category agreement and secondary Low/non-Low agreement,
with All-Low on the identical case/domain denominator. Report confirmed and reconstructed
strata separately plus combined sensitivity and pending/mismatch coverage. Score overall
only when published and applicable; DAPA-HF overall is not given. Do not invent it or impose
a universal Some Concerns count instead of qualified Cochrane confidence.

A defensibly linked non-Low case is necessary for headroom above All-Low. Two all-Low cases
can reveal false alarms but cannot demonstrate improvement. If non-Low linkage remains
unresolved, report feasibility and stop that accuracy claim; neither weaken matching nor
discard all human evidence. Independently review disagreements against sources, separating
defensible disagreement from arithmetic, reading and rule errors. AI source-aware review
supports auditability, not independent expert validation. Do not rewrite reference labels
using model disagreement. Existing sealed outputs cannot establish gains from later changes.

This selected two-case pilot is a mechanism/feasibility diagnostic, not representative
accuracy; domains within a case are not independent trials. A credible JAMIA comparison
needs a subsequently agreed prespecified larger linked sample, baseline, coverage and expert
disagreement review. This proposes that path without launching it.
