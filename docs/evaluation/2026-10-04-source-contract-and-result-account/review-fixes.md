Independent review fixes before any pilot
========================================

The pre-pilot review found nested count Evidence was not promoted/exported when a different direct Evidence supported the step observation. Domain save now validates and promotes every nested count basis, retaining the original step and its identity. A compact server-resolved handle-to-canonical-identity map accompanies the warrant; it contains no duplicate Evidence payload. Domain export includes these identities; both verifiers require complete matching Trial/handle closure against their independently validated canonical Evidence/source/visual assets, including historical warrants. Context can recover promoted counts after disposable handle/render/delivery caches are lost.

Known different scope no longer coerces genuine context or counterevidence into inference. Context/contradiction retain their roles with explicit relevance rationale; using the different-scoped fact as support still requires explicit inference/transfer. Unknown/partial/shared scope does not force NI. Original source scope, step IDs and historical snapshots remain intact; existing direct/indirect support is not silently converted.

Validation: focused Result-account suite 7 passed, including all three scope roles, distinct text A/visual count B, cache loss/context recovery/export through both verifiers, and missing/tampered/wrong-Trial nested bindings. Broader working/recovery run had 39 passes and one fixture failure (contradiction omitted its required implication); corrected fixture passed in the focused run. Earlier fixture assertion incorrectly expected unrelated text A in count projection; corrected to assert actual visual B. Lint, formatting, scoped type check and diff check pass. No paid inference or scientific accuracy gain demonstrated.

Remaining limits: non-count facts are model context rather than automatic enactment; reconsideration only tracks declared step dependencies; replacing a 24 KiB checkpoint does not merge omitted steps. Source/Result changes suppress old accounts; unrelated Domain commits preserve them. A wrong shared account can propagate across Domains. One real-case integration pilot must review scientific warrants and qualifier enactment, not just JSON or canonical acceptance.
