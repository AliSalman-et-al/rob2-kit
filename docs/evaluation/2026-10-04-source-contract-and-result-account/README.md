## Contract correction

A quoted excerpt may be shorter than its bound source window. The resolver
collapses only ASCII whitespace runs for matching and returns exact original
projection text, containing-window text, resolved line bounds and half-open page
codepoint offsets. It retains punctuation, case, numbers and signs. Noncontiguous
words, paraphrase, cross-source splicing, signed/decimal numeric fragments and
ambiguous repeated excerpts are rejected. Saved clauses resolve to one unchanged
field entry with its path and content identity; entries are never merged.
Original versus follow-up attribution uses the resolved excerpt's line span.
This is provenance validation, never semantic support certification.

## Scientific mechanism implemented

The experimental path reverses an existing dependency: participant-flow context
previously came largely from already-saved D2/D3 answers. Now an editable,
Source/Result-bound reconstruction can feed that same projection **before** any
judgment. Sources → selected Result production → official propositions → judgments.

A `result_account` in the existing working checkpoint holds connected factual
steps covering relevant assignment/course, outcome collection, analysis and
plan/report history. Each retains its original source-located observation,
optional explicit inference, counterevidence, unknowns and optional existing count
rows. It replaces overlapping notes/premises/drafts instead of becoming another
ledger. There is no required four-row checklist or exhaustive reading gate.
D2/D3/D5 recover the same account; absent observed counts stay absent even when
completion or analyzed counts are known. Caller previews and ordinary legacy
checkpoints remain supported.

Existing Evidence-basis `working_observation` accepts a returned step identity.
The server resolves it to the original observation and complete factual-step
snapshot. The original Evidence remains authoritative and must intersect the
step's Source locator. A host-declared known scope mismatch requires an explicit
transfer inference while preserving the source scope. Other scope interpretations
are host assertions, not server entailment. Modified or removed relied-on steps
flag affected answers for reconsideration without changing any labels. Changing
an unrelied step does not flag other answers. Account changes invalidate frozen
experimental context; unrelated canonical commits preserve source facts.

The assessment skill now explains reconstruct-then-apply: follow participants and
measurements through the selected result, then determine what each independent
Cochrane proposition can infer from those facts and qualifiers. The typed route
is explicitly experimental pending behavioral evidence. Official guidance,
legitimate probable judgments, full source/image recovery, atomic canonical
validation and historical bundles remain intact. No new MCP tool, canonical
record type, researcher gate, model loop, or automatic scientific classification.

The expected benefit is fewer silent arm/time/method transfers and improved
application of already-read qualifiers. This is an untested behavioral hypothesis,
not an accuracy claim. A wrong common account could contaminate several Domains;
editable uncertainty, adjacent Evidence and source recovery remain essential.
