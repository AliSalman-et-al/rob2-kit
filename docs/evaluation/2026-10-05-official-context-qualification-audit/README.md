# Official question-context qualification audit

Three independently demonstrable scientific overstatements were corrected in current production question guidance. This is a targeted source-fidelity correction, not general prompt shortening, new answer policy, a decision-table change or adoption of the official-only D3 prototype. No paid evaluation, corpus rerun, trial-label repair or merge occurred.

Authority: Cochrane RoB2, 22 August 2019, complete signalling-question elaborations in Boxes 4, 6, 8, 10, 11 and response framework §1.1. The freshly captured official 72-page PDF hashes to a9e9c4fdc4be2d29b5c0a1a6b828e09f2014a34f6d5c302a532f6153ea0fd670, matching the production provenance. [Official guidance](https://www.cochrane.de/sites/cochrane.de/files/uploads/RoB_2.0_guidance_2019.pdf). Raw PDF/extracted pages are private; selected unmodified, whitespace-normalized complete elaborations and extraction coordinates are test fixtures with attribution/license/provenance.

|Question|Concrete defect|Correction and retained control|
|---|---|---|
|D1.1|Local rule and NI anchor made a randomized label categorically NI despite the official circumstantial-inference exception; minimization wording also implied a separately established random element was necessary.|NI now requires no reasonable probable inference. General minimization inference is retained, alongside explicit nonrandom/predictable contrary evidence. A credible trial-context inference is permitted, not guaranteed; an uninformative label still supports NI.|
|D3.2|Local rule required sensitivity assumptions to match a **documented** missingness mechanism. A defensible range can address an unknown actual mechanism.|Removed the documentation prerequisite. Plausibility and exact-result relevance still matter; LOCF/MI based only on intervention group remain insufficient by themselves. Unknown mechanism does not automatically earn reassurance.|
|D4.4|No anchor required that influence **could not** occur, while official elaboration permits an unlikely-influence appraisal for observer outcomes without judgement.|Anchor now preserves unlikely influence. Judgment-based participant/observer/provider outcomes remain susceptible; 4.4 possibility remains separate from 4.5 likelihood. No theoretical-impossibility requirement is imposed.|

Complete official elaborations were restored for these three questions only, including the D1 qualification missing from the prior excerpt. Operational guidance version 1.0.15 records the change. The instrument has 22 signalling questions; the other 19 are unchanged. The audit matrix covers every question across all five domains. Some unchanged official excerpts are abridged, but corresponding qualifications were present in actual local context; this audit did not infer a scientific contradiction merely from excerpt length. No wholesale removal or official-only rollout occurred.

Actual delivery: before/after scientific snapshots came from live native MCP get_domain_context on an intact neutral workspace, with the test client following every pagination continuation. These are combined snapshots of actual typed responses, not claimed single-message request bodies. Neutral saved answers enable transport inspection only and are not scientific evaluation results. All 22 wording/options/activation predicates are unchanged. Result/Evidence, response framework, generic guidance/traps and comparison cards match across all 5 domains. Rendered diff identifies 10 changed question fields confined to 3 questions; pack metadata/content hash changes separately.

Source-fidelity tests compare the returned complete official text to independently captured PDF blocks and exact source/version/locator. contrasting-controls.json records eight source-grounded contrasts: circumstantial versus uninformative randomization reporting, general minimization versus known nonrandom allocation, plausible-range reassurance versus imputation alone, and nonjudgment mortality versus judgment-based assessment. Native tests ensure both boundaries remain available and do not implement another model-free answer classifier. These checks verify authority/content/delivery, not how a model will answer a new trial.
