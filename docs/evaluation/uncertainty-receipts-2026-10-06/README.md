# Declared uncertainty in compact receipts

The preserved Bendix trace establishes a projection gap, not storage loss. The model submitted an outcome-availability uncertainty in the typed `unknowns` field. Canonical storage preserved it, and all nine delivered Trial review fragments reconstruct a complete receipt with that same uncertainty beside the warrant. The submitted warrant already overstates what contactability establishes; the transport did not introduce that scientific inference.

The compact save receipt nevertheless reports `supported` and an empty `unresolved_premises` list. That list is derived only from formal limitation bases, independently of answer unknowns. The record therefore makes a declared gap invisible at the immediate audit seam.

The correction adds `declared_unknowns` to model-facing claim traces at save and subsequent Domain context. It copies the existing answer field without interpreting it. Support status, signalling answer, activation, judgment, canonical identity and historical verification remain unchanged. Formal unresolved premises remain distinct; an unknown does not automatically make a probable inference inappropriate.

The source-to-submission-to-storage-to-delivered-review comparison is in [bendix-trace.json](bendix-trace.json). This is a transparency correction; no behavioral or accuracy improvement has been established. No paid run is authorized for this change.
