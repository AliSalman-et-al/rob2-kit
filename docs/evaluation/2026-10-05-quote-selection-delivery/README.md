## Exact delivery diagnosis

The original supplement request included physical page 98, but its receipt delivered no page-98 text. It explicitly returned remaining windows 97:47–60 and 98:1–60. The agent did not continue them, despite the tool and guidance exposing this recovery obligation.

The packing estimator calculated 23,983 bytes while the actual public envelope occupied 23,149 bytes: an 834-byte discrepancy. The estimate retained default optional character fields and nonfragment page fields that final delivery removed. Source-handle normalization was not the cause. Packing and delivery now use the same existing compaction rules, preserving the 24,000-byte limit, request order and fragment recovery.

An offline stdio replay against copies of the frozen answer-free approved seed exactly reproduced the old receipt using the frozen installed wheel. Current code finishes page 97 and delivers page 98:1–9 in 23,965 bytes, with explicit remaining window 98:10–60. This does not deliver the entire SAP censoring passage and does not resolve the scientific D5 issue. Summaries are adjacent; private raw receipts remain in diagnostics.
