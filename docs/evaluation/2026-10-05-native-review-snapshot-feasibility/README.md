## What an eligible comparison would teach

If a future organically captured, complete native assessment has relevant linked
snapshots, the cheapest distinct test is two matched review continuations from
that exact state. Use one current runtime and the existing native review and
source/search/image tools; alter only whether `working_observation` is retained
in review bases, reproducing the old projection versus the repair. Freeze the
original captured corpus, exact Result/checkpoint/step identities, full linked
qualifiers, generic normal review task, common CLI model/config, the existing fixed 24,000-byte native review response budget (including
the unchanged wrapper-accounting policy) and server branches before either
invocation. This is not a configurable maximum-request argument; preserve the
ordinary pagination and complete-detail recovery instead of expanding one arm. Do not require a
new account, inject rival explanations, supply preferred answers or change source
recovery. Saved proposals/adoptions are normal assessment state, not gold labels.

Both arms must actually reach the same ordinary assessed-review branch and finish
all advertised review pages. Stop after one complete review pass per arm or a
genuine technical/workflow blocker; do not continue to improve an answer. Freeze
both outputs before inspection. Source-first review would ask whether an
originally authored qualified inference/unknown survives **use** in the revised
warrant, whether unsupported certainty increases, and whether source-grounded
corrections are defensible. Preserving a legitimate probable inference is a
positive control; refusing to infer anything without exact counts is a failure.
Identical answers alone do not establish benefit, and a changed label is not an
accuracy measure. Extra snapshot context length remains bundled with the content.

This would test reviewer-continuation use of a real existing representation, not
cold-start assessment, account-first superiority, semantic certification or
benchmark accuracy. If the chosen snapshot contains no material qualification,
the repaired payload is not delivered, or a different server branch is needed,
stop rather than manufacture exposure. The present inventory supplies no such
launchable fixture; wait for genuine capture instead of purchasing another
assessment merely to generate one.
