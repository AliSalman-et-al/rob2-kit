# Known source-reading gaps: frozen EXSCEL and EMPEROR audit

Decision: reject a runtime patch. These traces demonstrate incomplete scientific investigation, but do not demonstrate a lost registered reading obligation. No model calls, new scientific source reading, benchmark execution, or judgment changes were made.

EXSCEL's proposal main-report page 3, lines 46–51 explicitly names the Clinical Event Definitions section in the Supplementary Appendix. Recovery item 6 exposes source-bound appendix navigation, including stable projection identity and continuation cursor. The model did not request the definitions section. It read appendix pages 30–31 instead. No working checkpoint registered the named definition as an unread range, open question, or next action. Main-report completion therefore did not establish that this appendix section was investigated.

EXSCEL's actual transport continuation was preserved and enacted: recovery item 32 requested protocol pages 184–193 and returned pages 191 (from line 28), 192 and 193 as remaining windows. Item 33 requested exactly those windows and returned no remaining windows. Review items 35–37 and closure item 38 occurred afterward. The SAP continuation was complete; other unread analysis-plan passages and insufficient use of delivered passages remain scientific reasoning issues, not evidence of dropped transport metadata. Closure is not proof of semantic completeness.

EMPEROR's main page 3, lines 75–79 points to prespecified appendix definitions. Item 7 searched the appendix and exposed 34 matches, a truncated first batch and continuation cursor. Item 8 requested only page 21. Its last numbered line is “OR,” so the definition visibly continues beyond the selected page; the whole requested page was delivered and remaining_windows was empty. Page 22 was never requested or recorded as a checkpoint obligation. An unconsumed search cursor is available navigation, not a requirement to exhaust every match. This frozen run stops after proposal validation; it contains no assessment review or closure. Later operator-only continuation reading was not supplied to the model and cannot support its proposal retrospectively.

The existing WorkingCheckpointDraft already supports source-bound unread_ranges, open_questions and next_action. Investigation recovery retains source observations and declared unread ranges while marking dependent interpretations stale after applicable changes. Trial review offers reading recovery for unresolved premises with declared unread ranges. Neither trace called save_working_checkpoint. Adding a semantic detector for a named appendix, “OR,” or medical terms would create an unvalidated completeness inference. Making all accessible supplements mandatory would broaden the obligation without evidence. Neither is justified by these traces.

The remaining failure is model non-enactment: follow an expressly relevant reference or visible continued passage, record a bounded outstanding question when useful, and use retrieved analysis-plan evidence in the relevant judgment. These cases do not establish that an explicit checkpoint was erased at approval, review or closure. A future trace that registers such an obligation and loses it would justify a narrowly scoped lifecycle fix. No accuracy or attention improvement is claimed here.

`replay.py` regenerates `navigation-replay.json` directly from the frozen event files, records their SHA-256 hashes and asserts the exact requested/remaining-window lifecycle, lack of checkpoint registration, and different stopping boundaries. The packet preserves raw navigation and review metadata; its source text is already model-delivered evidence, not newly read scientific content.
