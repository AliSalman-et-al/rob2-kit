## Literature boundary

Use the parent's supplied independent primary-literature review as a design constraint, not as newly replicated evidence. [CRITIC (ICLR 2024)](https://proceedings.iclr.cc/paper_files/paper/2024/file/fef126561bbf9d4467dbb8d27334b8fe-Paper-Conference.pdf) supports externally grounded feedback in its tested tasks, but its QA implementation allows up to seven search interactions and carries meaningful overhead. [Chain-of-Verification (ACL 2024)](https://aclanthology.org/2024.findings-acl.212.pdf) supports answer-blind factual questions for factual assertions; demonstrated scope explicitly excludes incorrect reasoning steps. [Large Language Models Cannot Self-Correct Reasoning Yet (ICLR 2024)](https://proceedings.iclr.cc/paper_files/paper/2024/file/8b4add8b0aa8749d80a34ca5d941c355-Paper-Conference.pdf) cautions that intrinsic review can preserve or worsen reasoning errors and motivates equal-budget, non-oracle controls. None establishes a universal RoB2 critique stage or a remedy for correctly stated facts followed by an invalid relation. No literature search or model experiment was performed in this offline pass.
