# Bounded current scientific validation audit

Decision: no demonstrated correction warranted for the two candidate gates examined. Keep the prior D3.2 correction. No production code, canonical history, pack content, verifier or model answer changed. No model call, broad case search or benchmark execution occurred.

## Evidence and guidance boundary

The audit starts from current `application/domains.py` answer validation and existing rejected submissions. It uses the Code benchmark October 1 CANVAS trace directly, plus the retained An diagnostic explicitly derived from the same Code benchmark fixture. Older main-repository evaluations were not used as the case corpus. The replay records file hashes, complete selected calls and current source-located official question guidance. Existing local primary guidance was sufficient; no web search was needed.

Cochrane's 22 August 2019 response framework (full guidance p. 3, sections 1.1–1.1.1) distinguishes firm evidence for definitive answers from probable judgments. NI is reserved for insufficient reported detail **and** circumstances in which a probable judgment would be unreasonable. Yes/ProbablyYes and No/ProbablyNo have the same risk implications. This does not mean that any uncertainty contradicts every answer, nor that missing evidence proves the opposite proposition.

## Candidate 1: complete_claim_has_unresolved_premise

Current validation rejects Yes/No accompanied by an explicit answer-level scientific limitation, except D3.2 No. It does not reject merely because a working premise record or sufficiency projection says “unresolved,” and does not apply this restriction to probable answers. An unknowns array alone also does not trigger it. In this model, an answer-level limitation declares a material unresolved premise; ancillary uncertainty belongs in unknowns rather than being silently upgraded into a required premise.

The actual frozen An second submission asserts D2.6 No but declares uncertainty about whether the unanalyzed participants had missing outcomes or observed outcomes excluded, and whether analysis retained original assignment groups. Those are necessary facts for its stated claim of an inappropriate analysis. Box 6 p. 29 allows ITT and mITT excluding missing outcomes, and distinguishes these from naïve per-protocol/as-treated or eligible-participant exclusions. Thus seven unanalyzed participants alone does not establish definitive inappropriate analysis. Unlike D3.2 No, D2.6 No is not the proposition that reassuring evidence was unavailable. The retained rejection is defensible; it preserves the draft rather than changing an answer. A probable response remains available if the host supplies a warranted inference.

The D2.7 potential-impact uncertainty must not be turned into an actual-impact requirement. Its guidance asks about potential substantial impact, has no fixed percentage threshold, and the current gate allows probable answers with a limitation. This audit does not reinstate the earlier overbroad criticism of An's D2.7 or assert that its entire draft is scientifically correct.

## Candidate 2: answer_requires_direct_basis

Despite its name, this gate accepts direct_support, indirect_support and contradiction Evidence roles for definitive answers. It does not impose an exact timestamp or direct quotation requirement on probable answers: context, inference, valid scoped absence receipts and limitations are structurally supported. This is a minimum provenance/role contract, not a host-inference entailment adjudicator.

The October 1 CANVAS D5 attempts item_103 and item_105 fail typed counterevidence construction, not scientific chronology. Item_108 succeeds with D5.1 ProbablyYes, explicitly retaining missing earlier-plan contents and interim-unblinding uncertainty plus a source-bound counterpoint. The same scientific direction survives the repairs. Its justification cites continued blinding and unchanged primary objective as its inferential basis; this audit does not independently establish that inference as correct. It establishes that the application does not prohibit it or force NI because no exact chronology is known. Box 11 p. 63 requires applicable analysis intentions before investigator access to unblinded data, while changes before access or clearly unrelated to results do not raise selection concerns. The accepted uncertainty is therefore distinct from missing provenance, and no analogous strict chronology gate is demonstrated.

For D5.2/5.3, the question is result-driven selection among eligible measurements/analyses, not mere existence of multiple possibilities. The captured guidance and activation metadata preserve that distinction. Their No is not generally equivalent to “no reassuring evidence,” so extending the D3.2 exception to them from vocabulary alone is unwarranted.

## Existing D3.2 exception and other boundaries

D3.2 No identifies lack of reassuring evidence, without proving bias or resolving the missingness mechanism. The corrected code permits inspected context/inference or valid scoped no-hit receipts together with explicit limits; a limitation alone is insufficient. Its prohibited NI option and activation of D3.3 after No/ProbablyNo are official branch constraints, not confidence heuristics. The audit retains positive and negative controls for this distinction.

Malformed citation/counterpoint shapes, wrong Trial or Source identity, missing active answers and prohibited answer options remain separate structural/provenance/branch failures. A zero-hit receipt is a lexical retrieval fact, not semantic evidence of absence. A limitation can be retained without any no-hit search, or with a positive receipt; there is no mandatory search-exhaustion rule for scientific sufficiency. No blanket relaxation or source-pattern inference is justified.

## Limits and disposition

This finding is limited to the two current gates and the named traces. It does not prove all definitive claims have correctly categorized limitations or that hosts use probable answers appropriately. It does show no actual rejection here caused by an unresolved working-field status alone, no forced NI chronology policy, and no warranted second D3.2-style exception. Reject changes rather than infer a semantic contradiction from the word “unresolved” or silently accept unsupported reassurance. Canonical records and historical verifier semantics remain untouched; no accuracy gain is claimed.
