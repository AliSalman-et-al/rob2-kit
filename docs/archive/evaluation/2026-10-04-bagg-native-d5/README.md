## Independent scientific review

The official PDF hash matches the production source descriptor:
`a9e9c4fdc4be2d29b5c0a1a6b828e09f2014a34f6d5c302a532f6153ea0fd670`.
Box 11, pages 63–65, distinguishes timing from result dependence and requires
eligible alternatives **and** likely selection on results for affirmative 5.2/5.3.

- **5.1:** The SAP draft is dated March 2, 2020, after reported follow-up completion
  on February 3. This does not date unblinded access. NI is defensible, but not
  uniquely required: the 2015 protocol already planned assignment-group mixed
  models and blinded-statistician analysis. Matching earlier content can support
  a qualified probable inference; planned blinding does not prove actual conduct.
  An early amendment attributed to a repeated-measures power error is a separate
  stated non-result rationale, not proof of SAP timing or selective reporting.
  The reported follow-up date was read but its actual passage is absent from
  the 5.1 bases; the date itself is source-supported.
- **5.2:** The later schedule and reported Table 2 agree on 18/26/52-week pain
  results, including the nonsignificant 52-week effect. However, the earlier
  protocol page 4 specifies additional during/post-treatment assessment times;
  the model did not read this page or reconcile those intentions. This weakens
  categorical completeness, without proving measurement, withholding or
  result-driven selection. Its cited bases contain definition/methods passages,
  not the actual outcome tables supporting assertions about reported alternatives.
- **5.3:** The primary SAP/model/18-week contrast correspond reasonably to the
  reported assignment analysis. The separate complier estimate was not substituted
  for the target. Earlier prognostic-covariate wording, possible ATET analysis,
  and the eight-versus-nine-session compliance definitions merit qualification;
  their eligibility for this assignment-effect Result is not established. The
  asserted reported complier estimate appears on main page 8, read but absent
  from this warrant's bases. Multiplicity or a mismatch alone does not show
  selective reporting.

## Keep / revise / remove decision

Keep the compact optional capture as a bounded ergonomic capability verified by
neutral native tests, not as a demonstrated scientific improvement. It reuses one
existing basis field and WorkingNote representation without a new tool or ledger.
One natural-use exposure of the compact path is insufficient to decide that each
optional dimension is useless. Keep legacy serialization/bundle support.

Revise only generic D5 source-comparison guidance: reconcile relevant earlier
plan definitions and cite actual reported alternatives, rather than treating a
methods paragraph as proof of full reporting. This follows the observed omissions;
no mandatory field, count threshold, answer gate or scientific-pack change is added.
Remove the obsolete checkpoint-copy ceremony from the preferred path (already
completed in f7); do not expand scope scaffolding or claim its adoption.

For an already selected Evidence item, the mechanically verified optional path
changes **3 actions → 1**: checkpoint save/status/judgment become ordinary judgment
alone. Minimal additional scoped scalar occurrences change **14 → 2**: seven
checkpoint values plus seven repeated link values become text and relation once.
Unchanged judgment/Evidence/role fields are excluded. These are interface counts
verified by neutral native tests, **not actual behavioral savings in this D5 run**.
An unscoped compact interpretation adds only text; all semantic dimensions remain
optional. The actual D5 submission above adds none.

The previous checkpoint's native/legacy/visual tests establish mechanical capture
and quote/provenance preservation. This checkpoint runs focused legacy, integrated,
contract-budget and release checks. No paid post-guidance test was authorized;
its scientific effect is unmeasured. Full benchmark, merge and CI wait remain off.
