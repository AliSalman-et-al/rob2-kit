# Offline numerical-absence hypothesis: reject runtime annotation

A cheap absence aid detects the known Baby numerical attribution gap, but produces substantial noise on correct or legitimately derived numerical claims. **No opt-in runtime annotation was added.** There is no validator, automatic repair, required field, saving gate, default change, model call or assessment mutation. Claim-first packing remains on its previously tested visibility merits; the missed native citation defect remains recorded.

## Bounded, falsifiable design

The sample contains Baby's unchanged D4 differential answer and **17 control answers from 13 different Code Oct1 benchmark cases**. Controls were selected purposefully for arithmetic, rounding, confidence intervals, written numbers, units and basis roles, not randomly or as a benchmark accuracy estimate. Whole warrants, unknowns, basis roles, exact selected evidence and source identities were frozen; no sentence/clause was dropped to make a result favorable. These are controls for numerical premises, not endorsements of their scientific risk judgments.

All control bundles come from `/home/ali/Documents/Code/rob2-kit-benchmark/benchmark-luna6-medium-2026-10-01/cases`, not older main-repo evaluations. Baby comes from the legitimate finalized immutable fork already used for the native check. The independent verifier passed all 14 unique archives. Original archive hashes remained unchanged. No unrelated private files were scanned. The only extra source lookup was a read-only query of DAPA's already-captured main-source projection to confirm correct event counts elsewhere; its database bytes remained unchanged.

`protocol.json`, `sample.json` and `freeze.json` precede the first lexical results. An initial preparation assumption that all citations were narrative failed before results: several controls also cite stored `host_visual` figures. That failure is preserved. The sample was retained, and the source-type rule was clarified before testing: compare exact narrative quotes or existing host-authored figure transcriptions, separately tagged, without verifying the latter against pixels. No new OCR, rendering or native rerun occurred. Original image/render identities and source-recovery coordinates are retained.

## Existing machinery and its limits

The audit reuses `_NUMERIC_ATOM_PATTERN`, `_normalized_with_spans` and `_numeric_contains` from `application/evidence.py`. The product's number containment is explicitly **lexical**. It enforces full-number boundaries for Result leaf/source bindings and intentionally does not determine which arm, endpoint, unit or time point a number describes. `FieldEvidenceBinding` ties a Result field/path and value digest to an evidence index. Free-text Domain warrants have no equivalent per-clause numeric bindings.

Canonical normalization handles Unicode presentation, case, whitespace, soft hyphens and dash variants. It does not turn written numbers into digits, calculate fractions/sums, reconcile units or round estimates. It also does not turn the Lancet's decimal middle dot into a decimal point. Broadening this global normalization would affect source identities/selection/binding semantics and is not justified by this review hypothesis.

`DirectEvidenceUse.kind` and review basis roles are host assertions about how an entire source bears on a question. They do not identify which clause is reported versus calculated. Attal's correct count of 13 is in an `inference` basis because its downstream expectancy implication is inferred; suppressing such bases would lose a direct numerical premise. Conversely, Albert and Monarch legitimately compute numerical summaries using `direct_support` bases. Roles cannot reliably exempt computed numbers.

Existing `MissingDataRow` fields distinguish observed, analyzed, event and imputed quantities, preserve scope and source bindings, and `reconcile_missing_data` derives missing counts from randomized minus observed. Only one sampled warrant (NefIgArd) contains these optional typed rows. Its four missing counts—33, 36, 21, 17—are correctly derived but absent as source literals. All 12 randomized/observed/analyzed scalar checks are present; that presence still does not independently verify the field's scientific meaning. The existing derivation can explain these rows without inventing a general prose/arithmetic parser, but cannot bind Baby's untyped warrant clauses.

Exact existing recovery actions are available from source/evidence identity: `read_pages` for narrative spans and `render_page` for stored figures, using the current source-handle machinery. They recover **the selected source**, not a guessed repair page or proof of support. Adding an absence annotation would not itself find Baby's real main-p7 support.

## Actual flags, including every false alarm

The frozen candidate extracts numeric expressions (including slash ratios) from the normalized whole warrant, strips a percent suffix for the existing containment matcher, and compares each selected quote/transcription separately. It pools matches across existing bases without splicing text across sources. A flag means only **literal expression absent from the selected comparison material**.

It flags both Baby fractions, but also **9/17 controls**, with **34 control-expression flags**:

- **32 flags across eight answers** are legitimate arithmetic or representation: separately printed numerator/denominator counts, missing-count sums, rounded rates, thousands separators or decimal typography.
- **Two flags in DAPA's answer** identify a genuine selected-span attribution gap for otherwise correct numbers. The cited main p3 has the follow-up flow, not the 386/502 event counts. Those counts are explicitly in the same main source p1 lines40–41. This is useful localized absence, not scientific contradiction or false facts.

`adjudication.json` explains every flagged expression, including source context and calculations. [before-after.md](before-after.md) shows every control and Baby; both runtime annotation columns remain absent because the candidate was rejected. Representative noise includes 10/669 ≈1.5% in Monarch, 14=8+6 in Getgood, 2/978≈0.2% with written “Two” in AWARD, and 149/182≈82% in NefIgArd. All 11 NefIgArd point-estimate/CI flags are the publication's middle-dot decimal spelling. This is not a newly discovered scientific contradiction.

One **explicitly post-hoc exploratory sensitivity check** asks how much cheap component/presentation comparison can reduce this noise. It tokenizes numeric values using the same atom regex/normalization and standard-library `Decimal`, tolerating thousands grouping and digit-middle-dot-digit decimals. It treats slash fractions as components, never evaluating arithmetic. It has no word-number conversion, tolerance, role inference or case exceptions. Its protocol and script were frozen before its result; it is not independent validation or a substitute primary endpoint.

This reduces flags to **5/17 controls**: DAPA's two real span gaps plus **seven legitimate derived values across four answers**. Those residual values are Monarch's 10 and 1.5, Getgood's 14, NefIgArd's 82/80/364 and AWARD's 0.2. Baby still flags denominators 86 and 94. This is inadequate evidence of low noise for an annotation that would compete with material scientific review. No further rule-tuning or narrower parser was built.

Positive matches are also weak. Albert's value 18 matches RMDQ quartiles, rather than directly reporting the total missing-participant count. Getgood's 15 matches a 15% PRO missingness value, while its 15 missing LET participants require summing 10+5. The same value can refer to different units and outcomes. Written “Two” and “year one” are outside digit scanning. Neither lexical absence nor presence establishes scientific entailment.

## Decision and checks

Reject the runtime aid for now. Making this substantially less noisy would require knowing which numerical clauses are calculations, their operands/rounding, units and source context—information not reliably bound in current free-text warrants. Adding a parser, compulsory calculation fields or citation-repair subsystem would exceed the cheap hypothesis and risk distracting from scientific reasoning. Existing typed arithmetic should continue to explain its own quantities; it should not be repurposed into a validator of free-text judgments.

Four bounded checks pass: reproducible replay of all frozen cases with original-hash preservation; actual wrong-quantity/unit literal matches; valid derived typed missing counts; and correct DAPA counts outside the selected span with complete flag explanations. The changed audit test passes lint/format. Frozen primary/sensitivity algorithm files are historical experimental code, not installed product paths. No broad test suite or benchmark was run.

## Next highest-impact scientific issue: D3 assumption plausibility

**Prioritize whether a sensitivity analysis actually addresses plausible missingness mechanisms for the approved Result.** The frozen Attal assessment is a concrete candidate: SQ3.2 is `probably_yes`, yielding D3 Low, based on similar efficacy under LOCF, linear interpolation, maximum-likelihood mixed models and MCMC multiple imputation. The warrant acknowledges that departures from MAR/plausible MNAR scenarios were not tested and that missingness was more frequent late and in placebo.

Its selected supplement p15 goes further: it calls the pattern MAR and claims lack of a detected baseline effect rules out MNAR. That assertion does not establish the necessary relationship between missingness and unobserved pain values. “Arbitrary missing patterns” in the MCMC description is also different from robustness to arbitrary missingness mechanisms. Multiple method names or stable point estimates do not by themselves test the relevant assumptions.

The **current** pack already says SQ3.2 requires plausible assumptions relevant to documented missingness and true outcome (`packs/scientific.py`, guidance for `sq:missing:evidence-unbiased`). Therefore this is a source-interpretation/assumption-audit candidate, not a reason to add another blanket instruction. `next-scientific-issue.json` preserves the exact saved answer, source identities and passages. NefIgArd's Table S2 provides a useful contrast: its alternative imputation specifically conditions on treatment duration and later UPCR, rather than merely changing imputation method names. Neither case's label is revised here.

This is **not yet a confirmed Attal label error**: the actual missingness reasons, timing, methods' assumptions and approved longitudinal pain estimand must be assessed together before deciding whether MAR is plausible and what mitigation is justified. The next useful work is that bounded scientific audit, with suitable positive/negative assumption controls; another generic citation reviewer or literal-absence mechanism is lower priority. Full benchmark and merge remain held.
