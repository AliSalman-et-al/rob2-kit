# Use question-scoped staged Evidence obligations

Evidence breadth is governed by versioned Guidance obligations compiled for each signaling question. Each proposition has purpose-specific passes, each pass has additive source-role stages, and each stage contains exact engine-materialized navigation intents. Cheap, directly applicable sources are searched first; wider source roles activate only when Guidance makes them mandatory or a closed escalation trigger fires. Domain 5 plan-versus-report questions always include dated protocol, SAP, and registry evidence where available.

The engine, not the agent, owns procedural breadth: it materializes the complete Source inventory, exact authorized scopes, traversal and triage receipts, stage outcomes, and auditable stopping state. The agent owns semantic judgments within that envelope: query terms, evidence meaning, contradiction interpretation, and whether an observed trigger applies. Confidence cannot waive a mandatory stage or turn a coverage limitation into No-information.

Work advances through an immutable active-question frontier. A question answer requires both closed procedural evidence and an engine-frozen question Evidence Bundle with exact reviewed provenance. A terminal source or semantic limitation produces a judgment-free diagnostic Result instead of fabricating an answer. Question transitions are immutable; a Domain becomes visible atomically only after its active frontier is complete.

This replaces the active v2 rule that required three fully traversed full-corpus Search passes for every signaling question. V2 navigation records remain decodable for historical audit, but new writes use only the revision-keyed v3 workflow and public contract.

## Consequences

Search cost scales with the stages actually required by Guidance and observed evidence, rather than with the largest attached source multiplied by a fixed pass count. Source criticality remains an availability consequence, not an authority ranking. All applicable Source revisions remain visible in paged context, exact scopes fail closed when stale or tampered, and source unavailability requires an engine-issued acquisition-attempt receipt. Superseded searches remain auditable and every surfaced candidate still requires terminal triage.

For Domains 1–4, contradiction seeking starts with the primary report and widens to applicable companion reports, supplements, protocols, SAPs, and registry revisions only when conflicting evidence or structural ambiguity is observed. This preserves primary-first cost while preventing a primary-report-only contradiction check from being mistaken for adequate scientific breadth.
