# Permit source-bound visual methods transcription

Status: accepted design; implementation pending.

A methods statement visible in a delivered Source image may support an assessment
through literal host transcription even when extracted text omits it. Preserve
exact Source, page, region, and render provenance, identify the observation as
`host_visual`, and retain uncertainty or conflicting text rather than presenting
the transcription as machine-verified.

This broadens the permitted visual use described in the existing workflow
contract while retaining the distinction between delivery verification and the
host's interpretation of image contents.
