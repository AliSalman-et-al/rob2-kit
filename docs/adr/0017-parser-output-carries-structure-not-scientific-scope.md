# Parser output carries structure, not scientific scope

This decision supersedes ADR-0005 and generalizes ADR-0002 and ADR-0016: parser output and Canonical evidence units carry only source-preserving structure used for deterministic reconstruction, reading, and provenance, while Trial, Result, Domain, and signaling-question meaning is established by engine-issued scope plus attributable exact-span review. Parser-derived scientific labels, applicability, and dead search refinements are removed instead of being wired into eligibility; this deliberately trades automatic semantic filtering for broader agent inspection in bounded context without allowing parser imprecision to hide or authorize Evidence. The change creates new canonicalization and Evidence-contract revisions, rebuilds the derived index, and requires explicit reprocessing of invalidated dependencies without compatibility aliases or reinterpretation, while historical ledgers and reports remain inspectable.
