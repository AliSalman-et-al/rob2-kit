# Retain current overall aggregation during the post-benchmark repair

Status: accepted

The 21 September 2026 audit questions whether multiple `Some concerns` Domains
should produce `High` without an additional judgment that the combination
substantially lowers confidence. Keep the current deterministic aggregation for
this repair program so historical and new assessments use one stable policy,
while making its drivers auditable and evaluating the policy separately against
independently adjudicated cases. This decision does not claim that the current
rule is scientifically final; changing it requires a separate explicit decision
with versioned compatibility consequences.
