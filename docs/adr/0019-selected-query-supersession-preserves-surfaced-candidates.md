# Selected-query supersession preserves surfaced candidates

Each mandatory signaling-question Search pass has one explicitly selected query: a replacement must name and supersede it, only the selected query must reach full traversal, and superseded attempts remain auditable. Every candidate already displayed by any attempt still requires an explicit Search result disposition and may be retained, preventing query refinement from erasing potentially material evidence while avoiding forced traversal of an abandoned query.

## Consequences

The engine rejects accidental additional queries for an occupied pass, retains supersession history, and requires the final three selected mandatory-pass queries to be distinct. High-cost queries return a bounded first page and require an attributable choice to refine through supersession or continue traversal.
