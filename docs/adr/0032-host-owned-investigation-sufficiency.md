# Keep investigative sufficiency with the host

Status: accepted design; implementation pending.

Search exhaustion and zero-hit receipts describe lexical retrieval, so they must
not gate whether a scientific limitation is acceptable. The host supplies the
unresolved premise and stopping rationale; the server retains structural,
ownership, reference, and delivered-Evidence checks without claiming to validate
scientific sufficiency.

Search purpose is optional and independent of workflow order; omitted purpose
means Trial-level discovery and an initial purpose does not restrict later use.
Valid source-bound working notes may replace the duplicate postapproval report
pass, with reorientation for stale notes and relevance reassessment for changed
Results. This revises the corresponding workflow and discovery decisions in
ADR 0031; it does not weaken Proposal Review or Evidence provenance.

Context compaction continues through durable working-checkpoint recovery. A hard
usage-limit interruption resumes from the newest valid durable state when
execution is available, without repeating Proposal Review or discarding saved
judgments. Neither event is a scientific limitation or grounds to choose an
answer; exact source passages and pack guidance remain recoverable independently
of conversational summaries.
