# Reconstruct a selected Result upstream of Domain answers

Status: experimental prototype; behavioral benefit unproved.

The exposed corpus contains factual scope transfers and true qualifiers that
are not enacted in answers. Freeman's source-check reviewer had the correct
full flow and selected Result yet endorsed another arm's adherence reason.
A further reviewer layer is rejected for default adoption. Current flow context
largely derives from already-saved D2/D3 answers; that is too late to provide a
shared factual basis before the first judgment.

Reuse the replaceable, Source/Result-bound working checkpoint as one upstream
account of selected-Result production. It consists of editable source-located
steps with uncertainty, counterevidence and optional existing count rows. This
route replaces overlapping notes/premises/drafts, preserves full source recovery,
and leaves ordinary legacy notes and historical canonical identities intact.
Existing flow reconciliation consumes account counts before Domain saves.
Existing evidence-basis observation snapshots resolve references to account
steps; a known scope transfer requires an explicit inference and retains source
scope. Content dependencies flag relied-on changed steps without changing labels.
No new MCP tool, canonical record kind, researcher gate or automatic judgment.

The host procedure is reconstruct-then-apply, not a new semantic validator.
Questions remain independent, official Cochrane guidance remains authoritative,
and missing facts do not mandate NI, exact denominators, MNAR analyses or timestamps.
This amends the investigation approach in ADR0032 while preserving atomic Domain
submission in ADR0036. Account typing stays experimental pending fair behavioral
comparison. A wrong common account can contaminate several Domains; source
coordinates, exact Evidence, counterevidence, editable uncertainty and dependency
snapshots remain essential. No paid calls are authorized by this ADR.
