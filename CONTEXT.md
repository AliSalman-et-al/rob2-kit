# RoB 2 Assessment

This greenfield package is a model-free FastMCP boundary for an RoB 2 assessment
workflow. Codex or Claude Code is the sole agent and model loop. The server will
eventually provide strict scientific models, evidence access, deterministic logic,
persistence, and rendering; issue #183 establishes only the installable skeleton.

The current-batch resource represents the absence of an active batch as strict
structured data. The portable host skills are named `rob2-workflow` and
`rob2-signalling`; they divide host instruction and are shared rather than copied
into host-specific adapters.
