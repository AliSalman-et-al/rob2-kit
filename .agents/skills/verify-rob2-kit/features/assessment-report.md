# Assessment report

Finalizing renders a reviewer-facing report beside the bundle, at
`<workspace>/reports/<date>-<bundle id>/`. It has a Batch page (`index.html`)
with one row per Trial and one Trial page per Trial with every question,
answer, justification and quotation. `rob2 report BUNDLE` renders it again.

## Sub-features

- `finalize-report` makes `finalize_batch` write the report and return `data.report.path`, or `data.report.unavailable_reason` with the bundle still finalized.
- `batch-page` shows, per Trial, the assessed Result, D1–D5 and Overall in robvis colours with ✓ / ! / ✗, and not-assessed Trials with their reason and missing facts.
- `trial-page` covers:
  - the approved Result (outcome, time point, comparison, estimate, population);
  - for each domain, the algorithm judgment and the adopted judgment, with any adjudication;
  - for each question, its official number and wording, the answer, the justification and the quotes (file · page · lines);
  - counterevidence, unknowns, absence searches, Decisive badges and "Not applicable" for skipped questions.
- `rerender` writes the same pages elsewhere with `rob2 report BUNDLE --output DIR`.
- `refuse` makes `rob2 report` on a bundle that fails verification exit non-zero, naming the verifier's reason, and write nothing.

## How to get to it (user POV)

- Finish an assessment. The host reports `data.report.path`, and the researcher opens `index.html` in a browser.
- Run `rob2 report path/to/bundle.rob2.zip [--output DIR]` in a terminal.

## Driving it with the e2e Agent

Preconditions: a finalized workspace from `drive.py assess` (use `--keep-workspace`) or from a custom drive.

- **Finalize.** `agent.finalize()["data"]["report"]["path"]` points to `reports/.../index.html`, and `unavailable_reason` is `None`.
- **Batch page.** The summary table (the text before the first `</table>`) has six `title="Low risk"` dots for `prevent-tia`: D1–D5 and Overall. The page links `trials/prevent-tia.html`.
- **Trial page.** It contains `Was the allocation sequence random?`, the quote `computer generated by an independent statistician` and the justification text.
- **Look at it.** Serve the folder with `uv run python -m http.server 8765 --bind 127.0.0.1 --directory <report dir>` and open it in the browser pane. Screenshot the Batch page and one domain in both light and dark schemes (`resize_window` with `colorScheme`). Stop the server afterwards.
- **Refuse.** Tamper with `canonical.json` in a copy of the bundle. `rob2(ws, "report", str(tampered), "--output", str(out))` exits non-zero with `verification failed` on stderr, and `out` does not exist.

## Gotchas

- The browser pane cannot drive `file://` pages. Serve the folder over HTTP.
- The legend repeats the judgment dots, so count dots only inside the summary table.
- Reports render only bundles with a report-format marker. Older bundles verify, but they are declined.
- Collapsed quotations expand for print through `::details-content`, which Chromium supports. In other browsers, open them first.
